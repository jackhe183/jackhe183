## 关于我

我是 Jack，也叫 Lemon / 柠檬，现居中国杭州，是一名 AI 评测工程师。

我关注大语言模型的可靠性和开发者工具。我喜欢把有关模型行为的问题转化为测试、易读的结果和实用工具。

## 当前关注

- **大语言模型评测：** 让 Benchmark 结果更容易查看和比较。
- **模型探针与 API 兼容性：** 探索模型的行为，以及不同 LLM API 之间的差异。
- **Agent 评测：** 测试多轮对话，检查工具执行过程。
- **开发者工具：** 通过 MCP 和自动化，将 Agent 接入实际工作流程。

## 代表项目

- **[X7AgentEval](https://github.com/jackhe183/X7AgentEval)** — 通过模拟用户的多轮对话、执行日志和 Markdown 报告，评测 X7 客服 Agent。
- **[zoda-kina-explorer](https://github.com/jackhe183/zoda-kina-explorer)** — 用于查看 KINA 评测证据、比较模型准确率、成本和观测延迟的原型工具。
- **[bocha-search-mcp](https://github.com/jackhe183/bocha-search-mcp)** — 通过 MCP 为 Agent 提供博查网页搜索、结构化搜索结果和语义重排能力。
- **[pdf-statement-processor](https://github.com/jackhe183/pdf-statement-processor)** — 将 PDF 银行对账单中的表格提取为 Excel，支持分阶段处理和可视化调试。
- **[LLMprobe-engine](https://github.com/jackhe183/LLMprobe-engine)** — 我 Fork 的 [Bazaarlink 模型探针引擎](https://github.com/Bazaarlinkorg/LLMprobe-engine)，用于测试 OpenAI 兼容端点，并通过行为探针探索模型身份。
