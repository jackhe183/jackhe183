## About Me

I'm Jack, an AI Evaluation Engineer based in Hangzhou, China. I also go by Lemon.

I focus on LLM reliability and developer tools. I like turning questions about model behavior into tests, readable results, and useful tools.

## What I'm Working On

- **LLM evaluation:** making benchmark results easier to inspect and compare.
- **Model probing and API compatibility:** exploring how models behave and how LLM APIs differ.
- **Agent evaluation:** testing multi-turn conversations and reviewing tool execution.
- **Developer tools:** connecting agents to practical workflows through MCP and automation.
